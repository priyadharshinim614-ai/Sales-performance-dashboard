# Sales-performance-dashboard
Sales data cleaning and dashboard using google sheets
Sales Performance Dashboard

## Project Overview
An interactive and dynamic Sales Performance Dashboard created to analyze key business metrics, track sales trends, and deliver actionable insights for better decision-making.

## Key Features
- *KPI Tracking:* Total Revenue, Total Profit, Sales Volume, and Profit Margins.
- *Trend Analysis:* Monthly performance breakdown.
- *Category & Region Insights:Sales by region, and customer segments.

## Tech Stack & Tools Used
- *Google Sheets:* Data cleaning, formulas, Pivot Tables, and Dashboard creation.
- *Techniques:* VLOOKUP/XLOOKUP, INDEX/MATCH, Conditional Formatting, Data Validation, Charts & Visualizations.
  
## Project Structure
- dataset/ - Raw and cleaned sales datasets used for analysis.
- Sales_Dashboard.xlsx - The complete dashboard workbook.
- README.md - Documentation of the project.
  
## How to View
1. Download or clone this repository.
2. Open the .xlsx file using Microsoft Excel or import it into Google Sheets.
3. Use the filters/slicers on the dashboard sheet to interact with the visual reports.
